# Wisp Desktop

카카오톡 봇 스크립트(Wisp 레거시 API)를 **PC에서 바로 테스트하고 디버깅**할 수 있는 데스크톱 편집기입니다.
카카오톡이나 안드로이드 기기 없이, 메시지를 입력해서 봇의 답장을 확인하고, 중단점을 걸어 코드가 어떻게 도는지 한 줄씩 따라갈 수 있습니다.

## 주요 기능

### 강력한 디버거
- **중단점**: 줄 번호 띠를 누르거나 `F9`로 찍습니다. 실행 중 그 줄에서 멈춥니다.
- **단계 실행**: 계속(`F8`), 한 줄 실행(`F10`), 들어가기(`F11`), 나가기(`Shift+F11`).
- **멈춘 줄 표시**: 멈춘 파일을 자동으로 열고, 그 줄을 색으로 강조하고 줄 번호 옆에 화살표를 그립니다.
- **호출 스택**: 지금 어떤 함수가 어디서 불렸는지 보여 주고, 항목을 두 번 누르면 그 위치로 갑니다.
- **변수 트리**: 멈춘 순간의 변수를 객체와 배열까지 접었다 펼치며 봅니다. 값은 종류별 색(문자열, 숫자, 객체, 함수)으로 구분합니다.
- **감시식**: 원하는 식(예: `msg`, `user.name`, `items.length`)을 넣으면 멈출 때마다 자동으로 계산합니다. 감시식은 값을 복사한 공간에서 계산하므로 실제 변수를 바꾸지 않습니다.
- **마우스 값 보기**: 멈춘 동안 코드의 이름 위에 마우스를 올리면 그 값이 트리 모양 툴팁으로 뜹니다.
- **중단점 목록**: 걸린 중단점을 한눈에 보고, 두 번 눌러 이동하거나 지울 수 있습니다.
- **하단 디버그 탭**: 콘솔 옆에 있으며, 왼쪽 아이콘 탭으로 호출 스택, 변수, 감시식, 중단점을 나눠 봅니다.

### 편집기
- 여러 파일을 탭으로 열기. 탭 드래그로 순서를 바꾸고, 핀으로 맨 앞에 고정할 수 있습니다.
- 탭 우클릭 메뉴(닫기, 다른 탭 모두 닫기, 모든 탭 닫기, 경로 복사 등)와 모든 탭 목록 버튼
- 자동완성(`Ctrl+Space`), Ctrl+클릭 또는 `F12`로 함수와 변수의 정의로 가기
- 줄로 이동(`Ctrl+G`), 찾기와 바꾸기, 실행 취소와 다시 실행
- 설정 창(`Ctrl+,`): 글자 크기, 줄 번호, 자동 저장과 간격, 컴파일 전 저장, 시작 옵션
- 종료 때의 화면 배치와 열어 둔 탭을 기억해서 다음 실행에 그대로 복원

### 찾기
- 파일 찾기(`Ctrl+P`): 파일 이름으로 빠르게 열기
- 파일에서 찾기(`Ctrl+Shift+F`): 프로젝트 전체에서 문구를 찾고, 파일별로 묶어서 보여 줍니다. 결과를 누르면 그 줄로 갑니다.

### 프로젝트와 탐색기
- 프로젝트 폴더(`project.json` 순서대로) 스크립트 실행
- 스크립트와 리소스 추가, 삭제, 이름 바꾸기(`F2`), 다른 곳에서 가져오기(폴더째 가능)
- 스크립트 하위 폴더 지원, 탐색기 우클릭 메뉴 제공

### 컴파일과 테스트
- 컴파일 버튼 또는 `F5`로 컴파일하며, 진행 막대가 하단에 뜹니다.
- 컴파일 상태 보기: 스크립트마다 컴파일됨, 꺼짐, 오류 여부를 확인
- 콘솔의 컴파일 오류 줄을 누르면 해당 줄로 이동
- 테스트 제어판: 방마다 채팅창을 따로 열고, 메시지를 보내 답장을 확인. 긴 답장은 `전체보기`로 펼쳐 봅니다.

## 실행 방법

1. 배포 파일(`WispDesktop-x.y.z-windows.zip`)을 내려받아 압축을 풉니다.
2. 압축을 푼 폴더의 `WispDesktop` 실행 파일을 실행합니다. Java를 따로 설치할 필요가 없습니다.

## 주의

- 봇 스크립트는 포함되어 있지 않습니다. 사용자가 직접 가진 프로젝트 폴더를 불러와서 사용합니다.
- 데이터 폴더에는 봇이 쓰는 DB 파일(JSON)이 필요합니다.
- 디버그로 멈춘 동안에는 같은 실행 스레드를 쓰는 작업(컴파일, 채팅 메시지 처리)이 기다립니다. 계속을 누르면 다시 진행합니다.
- 감시식과 마우스 값 보기는 멈춘 동안에만 동작합니다.
- 중단점은 앱을 끄면 사라집니다.
